# Welcome to My First Scraper
***

## Task
This project top 25 trending GitHub repositories from a static HTML page and display their information in CSV format.
## Description
This project is a python web scraper that retrieves information about the top 25 trending GitHub repositories.
it extracts the following information:
- Developer
- Repository Name
- Number of Stars

The project usies the Requests library to retrieve the HTML page and BeautilfulSoup to parse and extract the repository information.

## Installation
Install the project requiered python libraries:
```bash
pip install requests beautifulsoup4
```

## Usage
Run the project using the following command:
```bash
python my_first_scraper.py
```
On linux use:
```bash
python3 my_first_scraper.py
```

The program displays the 25 GitHub repositories in CSV format
