# Welcome to My Cat Data
***

## Task
The objective of this project is to code a simplified version of the system `cat` command.

## Description
To solve this challenge in C, we used low-level system calls (`open`, `read`, `write`, and `close`) to read the files block by block

## Installation
To compile the program, use `gcc`
